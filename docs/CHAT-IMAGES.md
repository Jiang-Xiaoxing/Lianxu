# 聊天图片（本地测试功能）

聊天加号调用系统图片选择器，每条消息可带一张图片，允许只发图片或附加文字。发送前可查看和移除；未聚焦输入框时显示小缩略图，聚焦时自然展开为独立图片卡片。图片随消息保存在应用私有数据中，点击消息图片可以放大、缩放和拖动。选图和切换设置本身不请求模型。

## 明确选择看图方式

全局「辅助看图」开关在大模型配置的模型用途页，默认关闭。

- 关闭：把仍可用于本轮对话的已保存图片直接交给当前聊天模型。
- 开启：由明确选中的辅助看图模型观察图片，再把有出处的观察和文字交给聊天模型；聊天模型不收到原图。

程序不探测模型的看图能力，不自动换模型或改变这两条路线。缺少配置或模型拒绝图片时，保留原消息并显示错误，用户可以检查设置后手动重试。

再次追问时，关闭辅助会重新传送仍在有效近期上下文中的图片；开启辅助会结合新问题重新观察同一张图片。同一尝试内的工具续接可复用本次观察。已经整理退出近期上下文、撤回或停止AI使用的图片不会因这条规则被重新加入上下文。

## 资料、记忆与备份

图片导入后复制为应用自己的静态JPEG，去掉外部文件位置、文件名和照片元数据；聊天正文只保存用户原附文，纯图正文为空。发送前草稿保留在当前应用进程中，应用进程被结束后不保证恢复未发送图片。

辅助模型观察单独保存，包含原图哈希、原图消息和版本、提问消息和版本、模型出处。总结记忆可引用明确标注的图片观察，不能把它当用户原话；直传模式也保留该轮图片的出处元数据，不把像素另发给记忆或向量模型。仅有模型观察不能作为用户身份、偏好或承诺的原话证据。原图或提问来源改变、撤回及停止AI使用后，相关证据按现有人工、锁定和候选保护处理。

完整数据备份包含图片、消息关联、观察和相关来源；单角色备份不更改当前全局开关。全部覆盖恢复旧备份时，缺少开关按默认关闭处理。旧格式角色记录包不能携带图片，含图对话导出时会提示使用完整数据备份。撤回保留本地历史资源，完整备份仍可能包含历史图片。备份里的聊天和图片是普通ZIP资料；已有备份密码仅加密API密钥，不代表整包或图片加密，请按私密资料保管。

## 大小与使用范围

原文件最多24 MiB，检查尺寸后降采样、旋转纠正和等比缩小，最长边不超过1600像素，每张规范化图片最多512 KiB。一轮有效图片总数据上限1 MiB，超过时明确报错，不默默删图。图像会因缩小和有损压缩丢失细节，不保证小字和识别准确性。JPEG、PNG和WebP按静态图导入；其他系统可解码格式依赖Android版本，不保证动态内容或所有HEIF变体。

本功能的验收使用合成图片、隔离数据和模拟服务。实际服务商是否接受图片、真实识别效果、不同手机选图器及长期使用仍需对应环境验收。本地测试不等于正式发布。
