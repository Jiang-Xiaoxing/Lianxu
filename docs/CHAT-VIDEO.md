# 聊天视频

聊天左侧加号可以从系统选择器选一张图片或一个视频。视频沿用待发缩略图、移除、附文或纯附件发送流程；点开可用原生播放控制回看保存的完整原件。导入失败、取消或超限不会替换已选附件或清空附文。

在「设置 → 工具包 → 视频理解」选择发送方式。首次默认每秒抽取一帧，升级时保留已保存的选择。

- **直传原视频**：完整原字节，单个最多70,000,000字节，包含原有音轨和元数据。应用不压缩、不静音、不转码，也不单独提取处理声音；接收方可能理解原件中的声音。
- **每秒抽取一帧**：按视频画面轨时长，在0、1、2……秒各取一张完整画面，最后不足一秒也保留对应时刻；所有 JPEG 画面按时间戳顺序一次交给接收方，不发送音轨。不设20帧或普通图片数量上限，不稀疏抽样、不自动分批。准备全部画面前先按当前接收方配置的上下文容量做保守估算，容量或本机资源不足会明确失败。当前按每帧或整段视频 2048 token 粗估，与服务商实际计数可能有偏差，因此可能误拒或低估请求大小。

两种方式都沿用「图片理解」的接收方：辅助看图关闭时交聊天模型；开启且已选择辅助模型时交该辅助模型，再把标明派生来源的观察交给聊天模型。没有可用辅助配置会报错，不自动交回聊天模型。追问仍携带完整附件或重新观察，不把上次简短观察当成原视频。切换设置、来源编辑、撤回、遗忘、删除或取消后，旧请求不能凭迟到结果写入观察。既有锁定、来源版本和备份校验保留。

直传原件超过上限提示「暂不支持超过70 MB的视频」，不发送。70 MB是应用上限，服务商可能有更小限制或不接受视频/整组图片。当前网络实现使用兼容Chat Completions的 Base64 `video_url` 数据段（格式示例见[阿里云官方视觉文档](https://help.aliyun.com/zh/model-studio/vision)）；保存配置不代表该模型已支持。HTTP拒绝保留实际状态和错误正文（敏感内容遮去），不自动压缩、换方式、换模型或分批重发。

原视频始终在本机完整保存，发送所用的 JPEG 是本次临时副本。抽帧模式可读取超过 70 MB 的原件。JPEG 质量为 90，长边最多 1920、短边最多 1080，等比缩放。发送前按包含文字和 Base64 的完整图片请求核对本机 32 MiB 上限；服务商实际支持的图片数量、字节数和视觉上下文取决于接口与模型。完整备份会分块读取视频原件，按设备实际可用空间校验和恢复。原件会随备份一起保存。旧版仅文字角色包遇到图片或视频会要求使用完整数据备份。

验收区分本机TLS合成请求、专用模拟器与真实服务商/真实手机；前两者不证明真实模型的识别效果、费用或支持范围。
