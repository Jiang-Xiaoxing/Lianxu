# 本地更新说明与版本信息后端

本次只准备数据与持久化能力，没有新增页面、弹窗或自动启动行为。关于页和更新入口仍待图稿批准；现有界面不能视作已经改完。

`InstalledBuild.read` 从 Android 当前安装包读取包名、版本名和版本码，兼容 Android 8.0；读取失败直接交给调用方显示错误，不编造版本。作者使用用户明确指定的“江晓星”，开源许可为仓库的 GPL-3.0-only；仓库、许可全文与第三方致谢链接指向本项目公开文件，不添加私有身份、地址或账户。

`LocalReleaseNotes` 随安装包保存已核实的 v0.16、v0.17 发布摘要及测试限制。没有网络请求、远程更新检测或推送。历史查看只列当前版本及以前的已知条目；自动提示只匹配当前安装版本，不把一个未知开发版本当作旧版本更新。今晚未完成的功能不写成已发布；最终版本确实完成并发布前，需补充与其对应的真实说明。

`LocalUpdateRepository.pending` 只查询，不写已读。界面实际展示并由用户关闭后，才应调用 `acknowledge`；本次尚未接入这个调用。阅读记录按已确认的最高版本码保存，重复确认幂等，不因恢复较旧包而重弹旧版本说明。手动回看与已读状态无关。未知版本没有随包说明时拒绝写入阅读记录。

阅读记录是软件设置的一部分：全部备份带出，全部覆盖恢复；新增导入保留接收端记录，单角色包排除。旧备份缺少记录时默认为未读；新记录仍在原 SQLite 事务与全量恢复互斥边界内保存，没有新增数据库版本。

合成 JVM 测试覆盖版本匹配、首次/重复读取、版本递增与旧包行为、取消不写入、格式验证及手动历史；Android 测试覆盖实际包版本、持久化及备份范围。执行状态须以本轮构建日志与 PR 为准，编译 Android 测试包不代表设备运行通过。

摘要依据：[v0.16 发布](https://github.com/Jiang-Xiaoxing/Lianxu/releases/tag/v0.16-test.1)、[v0.17 发布](https://github.com/Jiang-Xiaoxing/Lianxu/releases/tag/v0.17-test.1)。
