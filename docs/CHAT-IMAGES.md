# 聊天图片（本地测试功能）

聊天加号调用系统图片选择器，每条消息可带一张图片，允许只发图片或附加文字。发送前可查看和移除；未聚焦输入框时显示小缩略图，聚焦时自然展开为独立图片卡片。图片随消息保存在应用私有数据中，点击消息图片可以放大、缩放和拖动。选图和切换设置本身不请求模型。

## 明确选择看图方式

全局「辅助看图」开关在大模型配置的模型用途页，默认关闭。

- 关闭：把仍可用于本轮对话的已保存图片直接交给当前聊天模型。
- 开启：由明确选中的辅助看图模型观察图片，再把有出处的观察和文字交给聊天模型；聊天模型不收到原图。

程序不探测模型的看图能力，不自动换模型或改变这两条路线。缺少配置或模型拒绝图片时，保留原消息并显示错误，用户可以检查设置后手动重试。

再次追问时，关闭辅助会重新传送仍在有效近期上下文中的图片；开启辅助会结合新问题重新观察同一张图片。同一尝试内的工具续接可复用本次观察。已经整理退出近期上下文、撤回或停止AI使用的图片不会因这条规则被重新加入上下文。

## 资料、记忆与备份

新导入的静态JPEG、PNG、WebP按原字节复制到应用私有数据，不统一转JPEG、不去元数据，保留透明度、颜色资料和EXIF。不会保存选择器外部URI或原文件名，但原文件内部可能含拍摄位置、设备、作者等隐私，发送原图也会把这些元数据交给所选服务商。聊天正文只保存用户附文，纯图正文为空。发送前草稿保留在当前应用进程中，进程被结束后不保证恢复未发送图片。

缩略图和放大查看都是原文件的有界渲染副本，按EXIF方向显示；未知方向标记按未旋转显示，不改写原件。放大时按可见区域重新读取细节，不用缩略图代替原件保存或上传。列表只保留小缩略图，点开时才读取完整文件。原件中颜色配置等数据不改写，但屏幕及服务商的颜色/方向处理仍取决于各自实现。旧测试版已经压缩成JPEG的历史图片继续读取旧副本，标记为历史压缩副本，不能声称恢复了原件。

模型派生图片观察单独保存，包含原图哈希、原图消息和版本、提问消息和版本、模型出处。总结记忆可引用明确标注的图片观察，不能把它当用户原话；直传模式也保留该轮图片的出处元数据，不把像素另发给记忆或向量模型。仅有模型观察不能作为用户身份、偏好或承诺的原话证据。原图或提问来源改变、撤回及停止AI使用后，相关证据按现有人工、锁定和候选保护处理。

完整数据备份包含原字节图片、原件/历史副本标识、消息关联、观察和相关来源；单角色备份不更改当前全局开关。全部覆盖恢复旧备份时，缺少开关按默认关闭处理；旧图片缺原件标识时按历史副本处理。旧格式角色记录包不能携带图片，含图对话导出时会提示使用完整数据备份。撤回保留本地历史资源，完整备份仍可能包含历史图片。备份里的聊天和图片是普通ZIP资料，原件里的元数据也随备份保留；已有备份密码仅加密API密钥，不代表整包或图片加密，请按私密资料保管。

## 大小与使用范围

20 MB明确指20,000,000字节（十进制），包含边界。不超过它的图片完整发送保存文件，发送字节和保存字节一致；不因长图而统一按长边缩小。超过它时，原件仍在本地保存，发送阶段才按原分辨率切局部：宽高最多2048、每轴204像素（约10%）重叠，按转正后的从上到下、每行从左到右顺序完整覆盖边缘，标注原始/正向坐标、顺序、原件哈希和方向；局部以PNG无损编码保留透明度，末尾附最长边不超过1024的全图总览。总览仅定位，不代替此前局部。2048/204是本项目工程参数，不是服务商标准。

单张发送文件最多20,000,000字节，每个完整请求体最多32 MiB，包含实际UTF-8 JSON、转义、图片base64填充、文字、工具和模型字段。图片编码通过流写出，避免同时构造整份base64字符串及JSON副本。两个单图都合规，不代表同一请求也合规；不会用一般HTTP 400推断“图片太大”。只有HTTP 413标为服务商请求体限制，其余保留原状态及正文；收到错误后不会自动降质、删图、拆批重发或换服务。

全部图片可以装入主模型请求时，关闭辅助仍直接发给主模型。需分批时先完整生成和检查所有部分，再依本地请求/所配置上下文预算分组；关闭辅助由同一主模型逐批看图，开启由同一辅助视觉模型逐批看图。每批带本轮新问题及完整次序，全部成功后再把各批带出处观察交聊天模型综合。任何批失败或全部观察超限都整轮失败，不把缺块资料当完整结果。服务商不支持多图时会直接报错，不预判能力、不根据错误自动改成单图服务。每次后续追问仍重新带原件或全套局部，不只复用旧描述。

调用/费用：主模型一次直接看完时为1次；辅助或必要分批时为N次图片观察+1次聊天综合（N是所有所需批次总数），同一尝试的工具续接复用本次观察；用户手动重试或新问题会重新调用，远端是否重复计费由服务商决定。本地幂等仅防重复消息/最终写入，不能保证远端计费幂等。诊断记录计划批数和实际HTTP调用，不记录图片编码。费用按用户所选服务商价格，本轮开发仅用合成图/模拟服务，没有真实模型消费。

本地资源上限：原文件最多40,000,000字节，单边最多65535、总像素最多160,000,000；一轮最多64张原图/局部/总览、准备发送文件合计最多96 MiB。完整备份单资源最多40,000,000字节，文字8 MiB、解压总量48 MiB、ZIP64 MiB；多张大原图可能超过备份总量，会明确失败，不生成缺图备份。实际设备内存或区域解码不足也明确失败，不承诺这些数值以内在所有手机都可处理。不支持动态GIF/APNG/WebP动画、HEIF/HEIC、TIFF等，不自动转码或只取首帧；超过20 MB的16位PNG保留原件但明确拒绝切片，避免暗中降到8位。单张来源观察文字仍限8000字符，全部观察不能装入时明确失败，不截断当完整结果。

本功能的验收使用合成图片、隔离数据和模拟服务。实际服务商是否接受图片、真实识别效果、不同手机选图器及长期使用仍需对应环境验收。本地测试不等于正式发布。
