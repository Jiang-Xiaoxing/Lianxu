# 关系历史回滚与最近一次重评

关系页提供已保存历史的预览和恢复。恢复需要明确确认，追加新关系版本，保留聊天、记忆和当前处理游标，不重新累计被恢复前已经处理过的聊天。恢复后，旧评估任务和候选不能覆盖新状态。

重评仅支持当前最近一次、且仍保留完整原批聊天和评估前状态快照的评估。导入资料、回滚结果、缺少快照或来源已经变化的历史不能重评。暂不重评更早批次，也不重放后续历史。生成候选会调用当前关系模型，可能收费；不会自动开启关系评估。

模型输入使用该批评估前状态与同一批原话，不把原评估结果当成新的起点。候选仅在页面内存中保留；显示六维当前值、候选值及简短说明，关闭或取消候选不写入。重复重评并采用仍使用该批原始起点，不重复累计增减。

明确采用时，在单一 SQLite 事务内重新核对角色、来源版本和快照、处理策略版本、模型配置及关系版本。失败、过期候选、重复采用和被取消的任务不能修改已保存关系；历史和当前状态一起提交或一起回滚。配置密钥不写入候选或历史。

此功能不增加逐维锁分、旧事件纠错或旧资料迁移。真实模型、真实手机与用户历史资料不属于本轮合成验收范围。
