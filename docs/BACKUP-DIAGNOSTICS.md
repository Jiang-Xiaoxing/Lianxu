# 完整备份与本机诊断

入口：设置 → 备份与诊断。本次沿用已确认的现有页面布局，没有增加头像上传、聊天附件或图片理解功能。

## 导出与导入

单角色导出包含该角色的持久化资料：名字/介绍/角色提示、表达与附加提示、聊天轮次及消息修订、当前记忆与版本历史、来源证据、候选及注入记录、关联/引用/召回使用记录、记忆整理历史与回执、关系状态/历史/评估来源快照、语气示例、处理策略及已保存的角色资源。当前头像由名字生成；资源存储支持按角色保存不透明头像/附件字节，尚无上传或发送入口。角色包不包含其他角色、全局设置或模型密钥。

全部备份另包含所有角色、昵称、紧凑显示、记忆数量规则、模型服务配置及用途选择。导出前必须选择“不包含密钥（推荐）”或“包含密钥”。包含密钥的包可跨手机恢复，不设密码，**取得文件的人也能使用 API 密钥并消耗额度**；这是敏感文件，不是防泄露的加密分享格式。排除密钥只移除模型配置中的密钥字段，用户自己写在聊天、人设中的秘密仍属于角色资料。

导入必须明确选择新增或覆盖，再预览影响范围。单角色覆盖还需明确选目标，不按名字自动匹配。新增只增加角色，不改变现有模型/用途设置，不启用包内服务或凭据，也不打断其他角色的在途请求。覆盖全部会替换所有角色和软件设置；覆盖前二次确认。

不包含密钥的全部备份覆盖恢复时，仅当服务 ID、供应商 ID、原端点完全相同时保留本机密钥。端点不符的新配置留空；无法匹配的原有带密钥配置单独保留但不自动选择，避免把密钥发到错误服务。包含密钥时使用备份中显式携带的密钥。应用内配置记录仍通过 Android Keystore 的 AES-GCM 加密保存，不导出存储密钥、签名密钥或平台凭据。

导入不调用模型。未完成聊天转为中断；未完成整理/关系任务归档并标记需手动重新执行，旧选择任务不恢复。已完成的历史、来源和回执保留。关系自动评估关闭，不恢复在途任务、工具执行状态和派生向量缓存。备份中的提示和文本只作为资料，不执行 SQL、脚本或归档路径。

所有数据库变更在一个事务中发布。模型恢复先在应用私有目录准备加密记录，通过同一数据库事务切换记录代次；失败不切换，提交后清理旧加密副本。预览同时绑定包内容和当前数据库/配置指纹，变化后需重新预览。提交前取消会回滚；提交决策先发生时，收尾和页面刷新仍完成，并明确显示已提交。新增/单角色覆盖只锁定短期本机变更，不使其他角色的有效回复失效；全量覆盖使旧任务失效。

## 格式与限额

新包为 ZIP，`manifest.json` 声明 `format=lianxu-backup`、`version=2` 和逐文件大小/SHA256；数据为 `backup.json`，资源仅为 `assets/数字.bin`。不解压到外部路径。压缩输入上限 64 MiB（包括尾部数据），展开总量 48 MiB，资料 JSON 8 MiB，单资源 16 MiB，最多 100 个角色、100 个模型配置、200000 条数据记录。写入也遵守这些限制，超限明确拒绝。资源采用分块 SQLite BLOB 读取，避免超过 CursorWindow。

旧 `lianxu-role` v1 包继续按原 32 MiB、文件清单、哈希及来源规则读取；旧包缺少的关联、配置等不能补齐，其原有覆盖语义在预览中说明。旧格式细节见 [ROLE-ARCHIVE.md](ROLE-ARCHIVE.md)。

## 本机诊断

平时记录实际排错过程，不自动上传。最多 5 段，每段 2 MiB，保留 7 天，写入队列 128 项且约 2 MiB；满时丢弃并标记。单事件输入过大整项丢弃，详细正文约 32 Ki 字符后标记截断。流式分片聚合记录，不逐片阻塞写盘；失败、取消或超限的未完整正文省略，避免残缺密钥前缀进入日志。

页面只有一个“开启详细诊断”开关，决定本次导出简版或详细版。简版保留事件/时间/版本/关联 ID/耗时与错误类别，移除数据正文；详细版可能包含聊天、记忆、提示词、工具参数及实际模型输出，应只向可信的人提供。

实际接线包括聊天持久化及结果、prompt 组装、模型用途/参数/请求/结果、HTTP/流式失败、工具调用、记忆提取/召回/排序/关联/写入/候选确认、关系评估/回滚/最近一次重评、包导入导出和数据库提交/回滚。嵌入路径记录模型/端点、数量、维度、状态和错误元数据，不记录原始记忆嵌入文本或向量。日志不记录或推测模型内部思考。

密钥、Authorization、Cookie、令牌及 URL 查询参数在入队和写盘前脱敏；响应、错误与堆栈同样处理。请求时重新注册该请求的密钥，避免注册表限额淘汰导致响应泄漏。导出头明确标记刷新完成状态、丢失数量、轮转/清理和历史限额；不保证日志覆盖被清理前的全部过程，也不将限额记录伪装为完整历史。

## 验收说明

只使用合成角色、假密钥、模拟接口和专用 Android 模拟器。检查构建、JVM、lint、单角色/全量往返、资源、密钥恢复与端点保护、失败/取消/预览变化、旧格式、在途请求隔离、脱敏/轮转/追踪链及系统文件保存选回。执行证据与未覆盖项见对应 PR；真实模型、真实手机、其他厂商文件提供程序仍需单独验证。本次没有发布新版 APK。
