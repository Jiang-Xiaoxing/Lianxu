# 恋叙界面规范

本轮采用用户确认的原创暖黄星月方向：暖纸色背景、深棕正文、克制的金色强调。使用原生 Material3 / Compose，共享 AppTheme、UiComponents 和 UiSpace，不为各页另建一套视觉系统。暗色主题独立配置可读颜色。

正文采用系统 Sans，品牌标题保留已有授权字体（见 BRAND-FONT.md）。标题 22/18/16sp，正文 16/14sp，说明 12sp；支持系统字体缩放。点击目标至少 48dp，保留滚动、IME 避让、返回与草稿。紧凑列表实际把上下间距从 16dp 改为 12dp。

底部顺序为聊天、通讯录、设置、我的。创建和寻找角色均保留；启动不添加演示角色。用户资料提供姓名、称呼、自我介绍，角色编辑以名字、角色设定、说话方式、可选开场白为主。聊天示例保留，高级提示和关系背景可展开，不改变工具权限。

设置目录分别进入模型、记忆、关系、备份诊断、显示、更新说明和关于。模型与备份沿用既有安全确认、取消、错误及密钥处理流程。关于页读取安装包的实际版本，并提供作者、许可、仓库和致谢。

图标采用用户确认的生图 v6 原文件；首页小图形只在前台且页面可见时呼吸，尊重系统关闭动画。其他页面不堆星月装饰。

记忆采用轻量透视投影星空，可转动和聚焦分类；这是 Canvas 交互视图，不是完整三维引擎。四类星点形状保持现有分类原名。只画真实正式记录，最多展示 60 个星点；候选独立，完整列表不截断。连线只用已保存且角色、版本、来源仍有效的关联，不制造装饰性关系。失败隐藏连线并提示，不影响列表操作。无持续后台绘制。

更新说明随包内置，不推送、不检查网络。首次阅读成功后记录版本，可在设置中回看。记录失败可以关闭继续使用，后续启动重试提醒。

验收区分代码编译、JVM、lint、设备实测及真实模型效果。静态稿不充当运行截图；模拟器不可用时不能宣称视觉、旋转、键盘、升级或设备数据库测试通过。
