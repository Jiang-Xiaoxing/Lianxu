# 品牌字体来源

左上“恋叙”使用Google Fonts的Ma Shan Zheng两字子集，文件为 `app/src/main/res/font/lianxu_brand.ttf`。正文与功能文字保持系统字体。

字体来源：[Google Fonts](https://fonts.google.com/specimen/Ma+Shan+Zheng)；[官方源码与OFL](https://github.com/google/fonts/tree/main/ofl/mashanzheng)。子集来自官方Google Fonts API，仅包含“恋叙”，不声称与概念字形或商业字体相同。
